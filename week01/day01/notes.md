## Core Memory / 核心记忆

- **Hugging Face = AI platform + developer ecosystem = AI 平台 + 开发生态**
- **Hub = 平台**
- **Models = 模型**
- **Datasets = 数据集**
- **Spaces = AI 应用 Demo**
- **Transformers = 使用 Transformer 模型的 Python 库**
- **Virtual environment = 隔离项目 Python 依赖**
- **Git = 本地版本管理**
- **GitHub = 远程代码仓库**

## Models / 模型

Models are trained AI models hosted on Hugging Face Hub.

Models 是托管在 Hugging Face Hub 上的 AI 模型。

---

## Datasets / 数据集

Datasets contain data used for training, validation, and testing.

Datasets 保存用于训练、验证和测试的数据。

Common splits / 常见数据划分：

- train
- validation
- test

---

## Spaces / AI 应用 Demo

Spaces are used to host and demonstrate AI applications.

Spaces 用于托管和展示 AI 应用。

---

## Virtual Environment / 虚拟环境

A virtual environment isolates Python packages and dependencies for a project.

虚拟环境用于隔离不同项目的 Python 包和依赖。

## Interview Practice / 双语面试练习

### Q1. What is Hugging Face?
### Hugging Face 是什么？

**English**

Hugging Face is an AI platform and developer ecosystem for sharing and using models, datasets, and AI applications.

**中文**

Hugging Face 是一个用于分享和使用模型、数据集以及 AI 应用的平台和开发生态。

---

### Q2. What is the difference between Models, Datasets, and Spaces?
### Models、Datasets、Spaces 有什么区别？

**English**

Models are trained AI models.

Datasets contain data.

Spaces host AI applications and demos.

**中文**

Models 是训练好的 AI 模型。

Datasets 是数据集。

Spaces 用于托管和展示 AI 应用。

---

### Q3. Why do we use a virtual environment?
### 为什么使用虚拟环境？

**English**

We use a virtual environment to isolate project dependencies and avoid dependency conflicts.

**中文**

使用虚拟环境是为了隔离项目依赖，避免不同项目之间发生依赖冲突。
